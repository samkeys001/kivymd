# TopAppNavigation

A simple KivyMD 2.0.1.dev app demonstrating a **Top App Bar** and **Navigation Drawer**.  

This project is updated to work with **KivyMD 2.0.1.dev** and Python 3.10+.  

---

## Features

- Top App Bar (MDTopAppBar)
- Navigation Drawer
- Clean, modern interface with KivyMD 2.x
- Fully compatible with **desktop (Linux, Windows, macOS)**  

---

## Requirements

- Python 3.10+
- Kivy 2.x
- KivyMD 2.0.1.dev
